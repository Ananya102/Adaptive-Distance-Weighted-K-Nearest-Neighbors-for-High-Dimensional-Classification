# Adaptive-Distance-Weighted-K-Nearest-Neighbors-for-High-Dimensional-Classification
This project focuses on improving the performance of classification algorithms using an enhanced version of the K-Nearest Neighbors (KNN) technique.
Traditional KNN models often suffer from limitations such as equal weighting of neighbors and sensitivity to the choice of K. To address these issues, this project implements and compares multiple variants including Baseline KNN, Distance Weighted KNN, and an Adaptive Distance Weighted KNN model.

The dataset used in this study is a binary classification dataset for predicting class labels based on multiple features. Various preprocessing steps such as feature selection, normalization, and correlation analysis were performed to improve model efficiency.

The performance of each model is evaluated using key metrics such as accuracy, precision, recall, and F1-score. Additionally, confusion matrices and graphical visualizations are used to analyze model behavior. The proposed Adaptive Distance Weighted KNN model demonstrates improved performance over traditional approaches.

The results indicate that adaptive techniques significantly enhance classification accuracy and reduce misclassification.
